# Finance
- O Personal Finance Manager é um sistema de controle financeiro pessoal desenvolvido para facilitar o gerenciamento de receitas, despesas e metas financeiras. O projeto busca oferecer uma visão clara e organizada da vida financeira por meio de registros de transações, relatórios e indicadores de desempenho financeiro.

# Objetivo
